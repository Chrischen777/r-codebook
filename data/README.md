# Classroom example data

- `nyc_flights.csv.gz`: the complete supplied NYC flights CSV, compressed without changing its contents (336,776 rows, 19 columns).
- Lecture 14 uses `lung_capacity.txt` from your own course materials. This raw dataset is not published in this repository. Place your local copy in `data` to run those examples.

Keep these files in the `data` folder of your RStudio project. R can read the gzip CSV directly. The website displays precomputed outputs and does not require these files to browse.
